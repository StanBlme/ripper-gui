# Ripper GUI

Een eenvoudige Python Tkinter-interface die het ripproces van ImgBurn automatiseert naar een nette mappenstructuur (`Filmnaam (Jaartal)`).

De code van dit project is initieel opgezet en vervolgens volledig geoptimaliseerd met behulp van AI om overtollige code te verwijderen en te zorgen een leesbare structuur.

## Installatie & Gebruik

1. Zorg dat [ImgBurn](https://imgburn.com) en **Python 3.x** zijn geïnstalleerd.
2. Open `config.py` en vul de juiste systeempaden.
3. Start het programma via de terminal:
   ```bash
   python main.py
   ```

## Disclaimer & ImgBurn
Dit project is uitsluitend bedoeld voor **educatieve doeleinden** en het maken van **persoonlijke back-ups** van eigen, onbeveiligde media.

* **Respect voor ImgBurn EULA:** In overeenstemming met de licentievoorwaarden van ImgBurn, wordt de software van ImgBurn door dit script op geen enkele wijze aangepast, gedecompileerd, gereverse-engineered of meegeleverd (hergedistribueerd). Dit script is een onafhankelijke 'wrapper' die een reeds op de pc aanwezige ImgBurn-installatie puur aanstuurt via de officiële command-line parameters.
